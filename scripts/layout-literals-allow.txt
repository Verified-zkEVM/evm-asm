# Layout-literal allowlist (GH #12586) — checked by scripts/check-layout-literals.sh.
#
# One entry per line, TAB-separated:
#   literal|arith <TAB> path <TAB> 0xvalue <TAB> count <TAB> reason
#
# `literal` entries cover bare hex/decimal occurrences of a canonical
# MemoryLayout constant's value; `arith` entries cover LUI/ADDI(W)/SLLI
# sequences that reconstruct the value from bare immediates. `count` pins the
# number of occurrences of that value in that file: adding one fails COUNT,
# removing the last one fails STALE and names the line to delete. An
# exemption that outlives its reason is how a backlog goes silent — update
# the pin consciously; that is the ratchet working, not the gate misfiring.
#
# Every entry must say WHY the occurrence is acceptable today and WHAT burns
# it down. The preferred fix for emitted code is the #12588 shape: derive the
# LUI/ADDI(W)/SLLI immediates from the MemoryLayout constant and #guard the
# encoding preconditions (4 KiB alignment, LUI immediate positive).
#
# LIMITATIONS of the gate (known blind spots, accepted by design):
#   1. A WRONG-VALUE literal that equals NO canonical constant is invisible
#      to detector 1 (e.g. a comment printing 0xbdb80000 today). Only
#      detector 2's range check catches reconstructed wrong values, and only
#      in [0xa0000000, 0xc0000000).
#   2. Near-miss literals (off-by-one hex digit) are undetectable without
#      flagging every hex literal in the tree.
#   3. Detector 2 sees only the LUI + contiguous ADDI(W)/SLLI shape with
#      bare numeric immediates; address materialization via LI, LD from a
#      symbol, or arithmetic spread across registers is not modeled.
#   4. RegionMap.lean is exempt wholesale as the second canonical site
#      (#12586); a stale copy there is invisible to this gate.
