# GH #12403 (cr track) — annotated exemptions for scripts/check-jaloff-closure.py.
#
# The gate requires every `jalOff` target of every `guestImageEntries` Program
# to itself be a `guestImageEntries` first component: an entry that jals into
# an unregistered routine executes code the `guestImageCodeReq` leaves
# unpinned, which blocks phase instantiation at the real image
# (`cpsTripleWithin_needs_entry_code`, TopComposition.lean). A target listed
# here is a KNOWN hole — the callee exists (and may even carry a proven spec)
# but has no entries row — with a reason and a tracking issue, or the gate is
# red.
#
# FORMAT (tab-separated, three fields):
#   <target-symbol>	issue=<NNNN>	<reason>
# Both the issue and the prose are mandatory — an exemption without a tracked
# issue is an unbounded one, and an exemption without a reason is the silent
# accept this gate exists to prevent.
#
# EXEMPTIONS EXPIRE ON THEIR OWN. If a listed target stops being violated (the
# callee is registered, or the last calling entry changes), the gate reports
# STALE-EXEMPTION and fails: this file cannot outlive its findings.
#
# Rows are keyed by TARGET symbol; the gate report names the calling entries.
# Only plain `GuestAddrs.<t>` / GuestLayout-field targets are exemptible —
# offset cross-entry jumps and non-GuestAddrs anchors are structural defects
# and must be fixed, not exempted.
