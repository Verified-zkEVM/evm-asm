# GH #12381 — annotated exemptions for scripts/check-rowed-liveness.sh.
#
# A registry row in EvmAsm/Progress/Routines.lean asserts that proven code is
# part of the guest's story. The gate requires each rowed symbol to be REACHED
# on the fresh link (direct call, branch entry, address materialization, or a
# dispatch-table word). A symbol that is reached by none of those appears here
# with a reason, or the gate is red.
#
# FORMAT (tab-separated, three fields):
#   <symbol>	issue=<NNNN>	<reason>
# Both the issue and the prose are mandatory — an exemption without a tracked
# issue is an unbounded one, and an exemption without a reason is the silent
# accept this gate exists to prevent.
#
# ONE SECTION, BY DESIGN. The orphan-block snapshot splits
# [baseline] (long-standing, unrefuted) from [known-open] (tracked defect). No
# such split exists here: an uncalled rowed symbol is either a deletion
# candidate or an indirect-dispatch fact, and both need a stated reason. A
# "long-standing" bucket would be exactly the rot this gate prevents.
#
# EXEMPTIONS EXPIRE ON THEIR OWN. If a symbol listed here becomes reachable, or
# leaves the registry, the gate reports STALE-EXEMPTION and fails: the file
# cannot outlive its findings.
#
# ⚠️ The gate never deletes and never chooses. Resolving a finding is a
# maintainer's call between (a) removing the code and its row in ONE PR — the
# #12351 pattern, both ledgers together — and (b) annotating here. Zero direct
# call sites is NOT proof of dead code (indirect dispatch), which is why the
# instrument also counts branch entries, auipc+addi materialization and
# non-.text address words before flagging anything.

[annotated]
